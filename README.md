# The Art of Business Dining

Responsive Angular website for the SP 18 SIE 415-515 business dining etiquette assignment.

## Run locally

```bash
npm install
npm start
```

Open `http://localhost:4200/`.

## Production and Vercel

```bash
npm run build
```

The production output is `dist/dinner/browser`. `vercel.json` configures the SPA rewrite so direct links to every educational page work after deployment.

## Included assignment requirements

- Internal navigation across the guide, survey, quiz, and references.
- External links to the University of Arizona and cited etiquette resources.
- Editorial photography and a table-setting infographic.
- Functional eight-question interactive quiz with scoring and feedback.
- All eight required student-learning survey questions.
